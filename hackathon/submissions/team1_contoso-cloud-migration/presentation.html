Challenge 2 — Discovery

The Things Nobody Documented

Claude was prompted to generate a realistic on-prem state — then find the dependencies that would break a cloud migration. These three findings shaped every decision after.

🔒 FinSecLib.dll — UNC Lock File

PCI tokenisation binary. No source. No vendor. Writes lock files to \\fileserver01\finlib-locks\ — a UNC share not in any architecture doc. Silent failure if share unavailable.

BLOCKS MIGRATION JIRA CLOUD-17

👻 Ghost VM — 172.16.4.42

Decommissioned server, still running. Recon calls it on every job: requests.get("http://172.16.4.42/api/validate"). Code comment: # TODO: remove after Dec 2022. Never removed.

BLOCKS MIGRATION JIRA CLOUD-33

🔗 ReportDB Linked Server

SQL Server linked server → creditcheck.ext.contoso.com:1433. External credit bureau. Called by SQL Agent job. Cannot be replicated in RDS. Firewall + DNS gap in cloud.

Challenge 4 — The Container

A Real Dockerfile, Not a Fictional One

Claude containerised the actual running app in this repo — the same inventory management system we've been developing. One prompt, one pass.

Dockerfile.backend — what Claude produced unprompted
# Stage 1: build dependencies
FROM python:3.12-slim AS builder
COPY server/requirements.txt .
RUN pip install --prefix=/install -r requirements.txt

# Stage 2: runtime — no build tools in final image
FROM python:3.12-slim AS runtime
# Non-root user — never run as root in production
RUN useradd --create-home appuser
COPY --from=builder /install /usr/local
COPY server/ .
USER appuser
HEALTHCHECK --interval=30s CMD python -c \
  "import urllib.request; urllib.request.urlopen('http://localhost:8001/health')"
EXPOSE 8001
CMD ["python", "main.py"]

Production patterns Claude applied without being asked

Multi-stage build

Build tools (pip, gcc) never enter the runtime image. Smaller attack surface, smaller image (~50 MB vs ~900 MB).

Non-root user

Container runs as appuser — cannot write to host filesystem even if compromised.

Health check endpoint

ECS marks tasks unhealthy and replaces them automatically. Claude added this before being asked.

Secrets via Secrets Manager

No secrets in image layers or plaintext env vars. Fixes ADR-002 hardcoded IP findings at the infra level.

Exact deploy path documented

docker tag → ecr push → ecs update-service — the exact commands to go from local to ECS.
